# Contributing to RideConnect

## Getting started

1. Clone the repository.
2. Create a feature branch from `main`.
3. Keep changes focused and use fictional demonstration data.
4. Test the relevant flow before opening a pull request.

## Commit style

Use short, action-oriented commit messages, such as:

- `Add recurring ride form`
- `Generate monthly ride report`
- `Improve keyboard navigation`

## Safety and privacy

Never commit real patient names, health information, Medicaid identifiers, credentials, or transportation confirmation numbers. The prototype is not affiliated with or endorsed by Medicaid, Washington Apple Health, any health plan, or any transportation provider.
